# ไฟล์โลโก้สำหรับแถบเมนู

เว็บใช้ไฟล์โลโก้กองบินตำรวจต้นฉบับที่ได้รับอนุมัติเป็นตราหลักทุกตำแหน่ง โดยใช้ชื่อดังต่อไปนี้:

- `police-aviation-logo-transparent.png` สำหรับแถบเมนูและหน้าเข้าสู่ระบบ
- `police-aviation-logo.png` สำหรับภาพต้นฉบับสำรอง
- `royal-thai-police-logo.png` สำหรับตราสำนักงานตำรวจแห่งชาติบริเวณด้านล่างของแถบเมนู
- `sidebar-background.png` สำหรับภาพพื้นหลังของแถบเมนู

แนะนำให้ใช้ไฟล์ PNG พื้นหลังโปร่งใส รูปทรงสี่เหลี่ยมจัตุรัส และมีความละเอียดอย่างน้อย 256 × 256 พิกเซล

หากยังไม่มีไฟล์โลโก้ ระบบจะแสดงสัญลักษณ์สำรองแทนโดยอัตโนมัติ
