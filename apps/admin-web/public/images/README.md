# ไฟล์โลโก้สำหรับแถบเมนู

นำไฟล์โลโก้ต้นฉบับที่ได้รับอนุมัติมาวางในโฟลเดอร์นี้โดยใช้ชื่อดังต่อไปนี้:

- `police-aviation-logo-transparent.png` สำหรับโลโก้กองบินตำรวจด้านบน
- `royal-thai-police-logo.png` สำหรับโลโก้สำนักงานตำรวจแห่งชาติด้านล่าง
- `sidebar-background.png` สำหรับภาพพื้นหลังของแถบเมนู

แนะนำให้ใช้ไฟล์ PNG พื้นหลังโปร่งใส รูปทรงสี่เหลี่ยมจัตุรัส และมีความละเอียดอย่างน้อย 256 × 256 พิกเซล

ไฟล์ `police-aviation-logo.png` เก็บไว้เป็นภาพต้นฉบับก่อนลบพื้นหลัง

หากยังไม่มีไฟล์โลโก้ ระบบจะแสดงสัญลักษณ์สำรองแทนโดยอัตโนมัติ
